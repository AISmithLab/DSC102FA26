AI resources for students

You may use the following links and promotional offers to access AI tools for the programming assignments. Register with a personal account and use your .edu email address when prompted to verify your student status.

OpenAI

Student offers:

  • ChatGPT student offer
  • $100 in Codex credits for students: Available to verified university students in the United States and Canada. The credits are applied to your ChatGPT account for use in Codex and expire 12 months after they are granted.

Choose either of the following coding interfaces:

  • Codex CLI: Follow the official installation guide, open your project directory, and run codex.
  • Codex app: Download and install the ChatGPT desktop app, sign in, and select Codex when starting a new chat.

Google

Claim the Google AI student offer, then choose either of the following coding interfaces:

  • Gemini CLI: Install Node.js 20 or later, run npm install -g @google/gemini-cli, and then run gemini. See the official installation guide for other installation methods.
  • Antigravity IDE: Download and install Antigravity IDE for a graphical coding environment with an editor, terminal, and AI agent.
